## Development

This repository is developed in a [KubeCoder](https://kubecoder.home/help/)
environment. Its curated entry points live in `.kubecoder/project.yaml`:

```sh
kc project setup   # create .venv and install requirements.test.txt
kc project test    # run the pytest suite
kc project lint    # ruff check
```

There is nothing to build — a HACS component ships as source.
